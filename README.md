# Europe Employment by Sex – End-to-End Data Science Project

## Project Overview
Analysis and forecasting of employment rates for men and women (age 20-64) in European countries, with focus on Croatia vs Germany.

## Business Questions
1. How has employment changed for men vs women in Croatia from 2005-2024?
2. How does Croatia compare to Germany (and EU average)?
3. Can we predict employment rates for 2025-2026?

## Data Source
**Eurostat** – Employment rate by sex (age 20-64)  
[Link to dataset](https://ec.europa.eu/eurostat/databrowser/view/tesem010__custom_21626893/default/table)

## Tools & Technologies
- Python 3.x
- pandas (data loading & cleaning)
- numpy (numerical operations)
- matplotlib & seaborn (visualizations)
- scikit-learn (machine learning)
